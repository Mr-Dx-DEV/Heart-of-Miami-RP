# FiveM Minigolf


A configurable Minigolf system for FiveM, allowing players to build, play, and compete on custom tracks. Supports ESX, QBCore, and standalone. Features leaderboards, inventory integration, replays, and scoring customization.

🔧 Customizable gameplay & framework settings
🏌️ Multiplayer lobbies with scoring system
