# rcore tattoos

### Installation

1) Go to data folder and copy addon tattoos folder
2) If you dont have create [tattoos] folder in your resources
3) Copy addon tattoos folder into [tattoos] folder
4) Add line into server.cfg to start tattoos - ``ensure [tattoos]``
5) Add it into your tattoo shop or use rcore_tattoos

### Rcore Tattoos shop integration

Package: https://store.rcore.cz/package/5199324
Documentation: https://documentation.rcore.cz/paid-resources/rcore_tattoos

1) Copy json file in rcore_tattoos folder into rcore_tattoos/client/assets/tattooLists
2) Open rcore_tattoos/config.lua
3) Add line into Config.TattooLists with name of file that you copy
