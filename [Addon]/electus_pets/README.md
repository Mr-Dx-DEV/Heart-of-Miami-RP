*Installation steps:*
1. Unzip the folder
2. Start the script in the server.cfg
3. Run the sql files through your database
4. Download electus_pets_extramodels from [github](https://github.com/ElectusM/electus_pets_extramodels). 
5. Add the item pictures to your inventory
6. Make sure you have a updated game build for all accessories to work properly can be found [here](https://docs.fivem.net/docs/server-manual/server-commands/#sv_enforcegamebuild-build)

Run esx_items.sql
