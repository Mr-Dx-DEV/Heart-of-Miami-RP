# HOW TO ADD NEW ACCESSORIES
1. Decide what new accessory you want (prop name)
2. Add it to Config.AccessoryKeys in accessory_creator.lua
3. Run /accessory_editor in-game
4. Save your configuration by clicking ENTER
5. Add your accessory configuration to pet_accessories.lua with the specific pet model

# HOW TO ADD OLD ACCESSORIES TO NEW PETS
1. Add your pet model in Config.PetKeys in accessory_creator.lua
2. Run /accessory_editor in-game
4. Save your configuration by clicking ENTER
5. Add your accessory configuration to pet_accessories.lua with the specific pet model

# Note
There is 2 bones one which will track with the body and one with the head.
